# Shade Mod (Fabric 1.21.1)
Сборка: JDK 21, затем в папке проекта:
    gradle wrapper
    ./gradlew build        (Windows: gradlew.bat build)
Готовый .jar: build/libs/shademod-1.0.0.jar
Положите его в папку mods вместе с Fabric Loader и Fabric API 1.21.1.

Моб "Тень": 30 HP, урон 6, спавнится в темноте, горит на солнце,
при ударе накладывает Тьму и замедление. Дроп: Эссенция тени (ночное зрение).
